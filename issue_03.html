The Interactive Handshake

В классической парадигме интеграции LLM и API вызов инструмента проектируется как слепая односторонняя транзакция: агент отправляет полезную нагрузку, сервер выполняет команду и возвращает 200 OK.

Для суверенных систем это критический отказ безопасности: теряется контекст времени, невозможно подтвердить факт осознанного шага агента, а любой сетевой сбой производит мусор.

В протоколе CyberSpark MCP реализован двухшаговый челлендж: сервер сначала возвращает дельту времени и 6-значный хеш сессии, и только затем принимает подписанный коммит.

КРИПТОГРАФИЧЕСКИЙ ЧЕЛЛЕНДЖ:
Δt = t_now - t_prev_checkpoint
Challenge = HMAC_SHA256(Secret, t_now || Session_ID)[:6]
Commit = today(hash="7f3b01", tag="...")

Инструменты ask_human, get_skill и save_skill замыкают контур, гарантируя, что критические действия проходят обязательное подтверждение оператора.
