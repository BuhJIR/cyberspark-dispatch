THE BURN-ON-TOUCH GATE

Проблема постоянного состояния: клиентские базы данных накапливают исторический контекст, раздувая сессионный оверхед до сотен мегабайт. Модель парализуется локальным шумом вместо оперирования строгими фактами.

Архитектура Zero-Trust решает задачу радикально: клиент объявляется чистым эфемерным терминалом с нулевым постоянным следом на диске. Память поставляется точечно через одноразовые криптографические коридоры.

Каждый токен генерируется в оперативной памяти сервера с жестким тайм-аутом: TTL составляет ровно 60 секунд в volatile RAM.

Доктрина сжигания при касании (Burn-on-Touch): любой входящий запрос (GET, HEAD или сканер портов) немедленно закрывает шлюз.

МЕХАНИКА АТОМАРНОГО СЖИГАНИЯ:
1. Socket Open ──► activeLeases.delete(tokenId)
2. Token Status = DEAD (0 ms)
3. Payload Stream = Direct Pipe to Socket
4. Re-access = HTTP 410 GONE

Первое касание сокета атомарно удаляет запись из памяти. Повторный запрос физически невозможен: шлюз возвращает 410 GONE.

Zero-Delay Ingestion

Агентский контракт исключает промежуточные паузы: в тот же миллисекундный шаг, когда шлюз возвращает токен, агент запускает прямой стриминг полезной нагрузки в изолированный временный пайп.
