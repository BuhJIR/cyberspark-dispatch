The Threshold Paradox

Why Traditional Noise Gating Destroys Weak Speech and How Pre-Normalization Inverts the Loss

В речевой акустике существует классический граничный сценарий: источник сигнала удален от мембраны, экранирован препятствием или шепчет. В нашем тесте уровень составлял -48...-45 dBFS.

Индустриальный канон десятилетиями диктует стандартную цепочку: Вход → Noise Gate → EQ → AGC/Compressor. Логика кажется незыблемой: «Сначала отрежь шум, затем усиливай полезный сигнал». Но на практике этот порядок превращает тихую речь в рваную цифровую тишину.

Причина кроется в физике речи: согласные звуки (фрикативы «с», «ф», «ш», «т») несут до 70% разборчивости, но их энергия на 15–25 dB ниже гласных формант.

dBFS 0 ────────────────────────────────────────── -20 ────────────────────────────────────────── -40 ─── Порог Gate (-42 dBFS) ─────────────── -45 ─── Гласные форманты (-44 dBFS) [ПРОХОДЯТ] -52 ─── Согласные речи (-52 dBFS) [СРЕЗАНЫ] ❌ -60 ─── Шумовая полка (-58 dBFS)
Оценка огибающей классического гейта
E[n] = (1 - α) · E[n-1] + α · |x[n]|
Gain[n] = 1.0 (E > T_open) : 0.0 (E < T_close)

При уровне -47 dBFS гласные звуки кратковременно приоткрывают гейт, но согласные мгновенно проваливаются под T_close. Гейт срубает атаку каждого слога. Последующий компрессор лишь усиливает уже изувеченные обрубки.

«Шумовой гейт, поставленный первым, судит о важности звука исключительно по его амплитуде. Для человеческой речи это смертный приговор.»

Surgical Inversion

Placing Slow-Release Adaptive Envelope AGC Ahead of Binary Hysteresis Decisions

Решение парадокса потребовало инверсии базового правила: AGC с медленной адаптивной огибающей выносится ВПЕРЕД шумового гейта.

Двухскоростная огибающая AGC
α_att = exp(-1 / (fs · 15ms)) [Атака]
α_rel = exp(-1 / (fs · 400ms)) [Удержание]
G_target = min( V_target / (E + ε), +48 dB )

Длинный release (400 мс) удерживает коэффициент усиления во время пауз между гласными, вытягивая тихие согласные из шума в рабочий диапазон -20...-16 dBFS. Только после этого гейт оценивает уже масштабированный речевой сигнал.
