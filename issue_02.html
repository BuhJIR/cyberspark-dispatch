Слепой вызов шелл-команды убивает прод за 140 мс. Двухшаговый шлюз блокирует исполнение до криптографического отпечатка.

The 2-Step Handshake

Иллюзия бесшовного вызова функций: маркетинговые демо обещают автономное управление инфраструктурой в один клик. В терминале в 03:17 модель с температурой 0.2 генерирует команду очистки кэша.

Случайная опечатка превращает строку в rm -rf / tmp/cache*. Незащищенный агент выполняет вызов напрямую в bash. Корневой раздел стирается за 140 миллисекунд.

Причина катастрофы: отсутствие двухшагового шлюза подтверждения намерений в транспортном слое JSON-RPC.

Архитектура Spark MCP исключает прямой вызов опасных операций. Инструмент today(tag="cache_purge") не модифицирует диск — он генерирует сессионный challenge-хеш 8daf47.

State = HALT (Token Pending)
CPU = 0.0% / RAM = 3.8 MB
Resume = HMAC_SHA256(Hash, Key)

Агент замораживает процесс, освобождая процессор до нулевой нагрузки. Исполнение возобновляется строго после ввода верифицированного хеша оператором.
